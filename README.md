# xjDAO AI

xjDAO AI 是一款多模型交叉验证 AI 助手 Web 应用。它的核心目标不是再造一个普通聊天框，而是让用户在一次提问中同时调用多个大模型，通过并行回答、差异对比、一致性分析和最终综合，得到更稳妥的答案。

> 当前版本是开源 MVP，适合继续接入真实后端、用户系统、会员系统、卡密系统、计费系统和部署流水线。

## 核心功能

- 类 ChatGPT 的聊天首界面
- 左侧会话栏、主聊天区、底部输入框
- 支持配置六类模型通道：
  - GPT
  - 硅基流动
  - DeepSeek
  - Grok
  - MiMo
  - Gemini
- 支持单模型问答
- 支持多模型并行问答
- 展示每个模型的原始回答
- 对多个模型回答进行交叉验证
- 提取一致观点、冲突点和最终综合答案
- 支持模型启用/禁用
- 支持 API Key、Base URL、模型名称自定义
- 支持亮色/暗色主题
- 支持基础 Token 与耗时估算展示

## 项目定位

xjDAO AI 适合以下场景：

1. **多模型对比问答**  
   同一个问题交给多个模型回答，减少单模型幻觉。

2. **AI 答案交叉验证**  
   对比不同模型回答中的一致点和冲突点。

3. **私人 AI 工作台**  
   用户可自带 API Key，按自己的模型资源使用。

4. **后续商业化扩展**  
   可继续加入会员系统、卡密兑换、后台管理、额度统计、团队空间和插件市场。

## 技术栈

- 前端：React + Vite
- 后端：Node.js + Express
- 样式：原生 CSS
- 接口模式：后端代理调用 OpenAI-compatible Chat Completions API

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/weeduon/xjDAO-AI.git
cd xjDAO-AI
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发环境

```bash
npm run dev
```

默认启动：

- 前端：http://localhost:5173
- 后端：http://localhost:8787

## 环境变量

复制示例文件：

```bash
cp .env.example .env
```

当前 MVP 默认由用户在前端设置页填入 API Key，并由后端临时代理请求。生产环境建议改为：

- 用户登录后保存 API 配置
- API Key 使用服务端加密存储
- 数据库使用 PostgreSQL / MySQL / MongoDB
- 增加调用日志、额度统计和异常审计

## 模型配置说明

每个模型通道支持以下字段：

| 字段 | 说明 |
|---|---|
| enabled | 是否启用该模型 |
| name | 模型通道名称 |
| provider | 内部供应商标识 |
| apiKey | 用户自己的 API Key |
| baseUrl | API 基础地址 |
| model | 模型名称 |

> 注意：不同平台的 Base URL 和模型名可能调整，请以各平台官方文档为准。这个项目保留自定义入口，不把配置写死，免得软件还没上线就被接口变动教育做人。

## 多模型交叉验证流程

1. 用户输入问题
2. 前端读取已启用模型配置
3. 后端并行请求多个模型
4. 返回每个模型的原始结果
5. 前端执行本地交叉验证摘要：
   - 哪些模型回答成功
   - 哪些模型失败
   - 高频一致观点
   - 明显冲突点
   - 最终综合答案

当前 MVP 的综合逻辑是基础规则版。后续可以升级为：

- 使用专门的裁判模型进行评价
- 为不同模型设置权重
- 引入事实检索和来源引用
- 对数学、代码、法律、金融等问题使用不同验证策略
- 引入 RAG 知识库

## 安全说明

当前版本是 MVP，不建议直接用于生产环境处理敏感数据。生产环境至少需要补充：

- 用户注册登录
- API Key 服务端加密保存
- HTTPS
- 请求频率限制
- 日志脱敏
- 数据库权限隔离
- 管理后台权限控制
- 防止 Prompt Injection 的安全策略
- 成本上限和异常调用报警
