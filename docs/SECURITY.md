# 安全说明

xjDAO AI 当前是开源 MVP，主要用于验证产品形态和多模型交叉验证流程，不是完整生产级安全架构。

## 当前密钥处理方式

当前版本中，用户在前端设置页填写 API Key。配置会保存在浏览器 localStorage 中，请勿在公共电脑或不可信环境中使用真实密钥。

后端只作为临时代理请求，不会在当前版本中长期保存用户 API Key。

## 生产环境必须增强

正式上线前，至少需要完成以下安全改造：

- 用户注册登录
- API Key 服务端加密保存
- 数据库存储隔离
- HTTPS 强制访问
- 请求频率限制
- 调用额度限制
- 敏感日志脱敏
- 管理后台权限控制
- 防止越权读取他人配置
- 防止恶意高频调用模型接口
- Prompt Injection 风险提示与隔离

## API Key 安全建议

- 不要把任何 API Key 提交到 GitHub
- 不要在截图、日志、Issue 中暴露 API Key
- 测试密钥应定期轮换
- 生产环境应为不同用户、不同模型设置独立额度限制

## 漏洞反馈

如果你发现安全问题，请优先通过私密渠道联系项目维护者，不要直接在公开 Issue 中贴出可利用细节。互联网已经够糟了，别再给爬虫喂武器。
